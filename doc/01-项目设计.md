# 项目概览
* 这是个前端项目，使用react开发
* 基于网站开发背景，线上网站名域名为www.fly-deer.com
    * 本项目：包含3个页面
        * / :作为网站首页
        * /user : 账户管理页面
        * /doc : 网站的支持文档列表
    * /strcut-mind 等其他页面由其他项目开发
    * 项目使用nigix管理各页面
* 支持gitee、github的Oauth登陆，支持手机号验证码登陆
* 使用jwt无状态token，包括accessToken和refreshToken，在api拦截器中实现自动刷新
* 网站图标使用/doc/assets/logo.png

# 首页
* 右上角登陆功能，登录时需要同意用户协议
* 包括网站介绍
* 主功能区为各具体项目的介绍和跳转
* 下方包括ICP备案、公安备案链接，包括服务条款、联系方式、投诉渠道、用户协议等文档

# 账户管理页面
* 设置登陆守卫，只有登陆态才能进入
* 展示用户信息、支持修改用户名称、支持Oauth登陆方式绑定手机号完成实名
* 代理授权管理服务，可以向用户发起授权，可以查看当前授权关系及状态并操作
