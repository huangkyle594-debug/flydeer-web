# UI 设计

> 第一阶段的 UI 模块划分与交互设计。整体走轻量、留白充分的工具类风格，桌面端优先，窄屏降级可用。

## 1. 页面结构

```
/                    首页：图集列表、搜索、新建、导入
/atlas/:atlasId      工作区：打开某个图集进行浏览 / 编辑
```

（实际部署时前缀为 `/struct-mind`，由路由 basename 统一处理。）

## 2. 首页（Home）

```
┌──────────────────────────────────────────────┐
│  Logo 飞天小鹭 · 结构化思维导图    [搜索框]      │
├──────────────────────────────────────────────┤
│  [ + 新建图集 ]  [ 导入图集 ]                   │
│                                              │
│  ┌────────┐  ┌────────┐  ┌────────┐          │
│  │ 图集卡片 │  │ 图集卡片 │  │ 图集卡片 │  ...    │
│  └────────┘  └────────┘  └────────┘          │
└──────────────────────────────────────────────┘
```

* **图集卡片**：名称、描述、图数量、更新时间；点击进入工作区；卡片操作菜单含重命名、删除、导出 JSON。
* **搜索**：按名称同时匹配图集与图。命中图时显示"图名 · 所属图集"，点击直达该图。
* **新建图集**：弹窗输入名称/描述，自动创建一张根图（入口图）。
* **导入图集**：选择 JSON 文件，校验后写入本地存储。

## 3. 工作区（Workspace）

```
┌──────────────────────────────────────────────────────┐
│ ← 返回 │ 图Tab1 × │ 图Tab2 × │ +   │ [浏览|编辑] 导出 ⌄ │  顶栏
├──────────────────────────────────────────────────────┤
│ 根图 / 子图A / 当前图                                   │  路径面包屑
├──────┬────────────────────────────────────┬──────────┤
│ 节点  │                                    │ 节点详情   │
│ 面板  │        React Flow 画布              │ (Drawer)  │
│(编辑) │   Background + Controls + MiniMap  │  点击节点  │
│      │                                    │  时弹出    │
└──────┴────────────────────────────────────┴──────────┘
```

### 3.1 顶栏

* **图 Tab 栏**：图集内已打开的图，多开但同时只有一张激活；`+` 新建图；`×` 关闭 Tab（不删除图）。
* **模式切换**：浏览 / 编辑 两态开关，全局影响画布与侧栏。
* **导出菜单**：导出当前图 JSON / 导出整个图集 JSON。

### 3.2 路径面包屑

* 展示当前图从根图开始的嵌套路径（由 `parentGraphId` 链推导），每一级可点击快捷跳转，体现"图在系统中的全局定位"。

### 3.3 左侧节点面板（仅编辑模式）

* 列出可用节点类型：第一阶段为 **基础节点**、**图节点**。
* 交互：HTML5 拖拽（dragstart 携带节点类型）到画布，落点即新节点位置；也支持点击面板项在画布中心添加。
* 拖入**图节点**时弹出选择：链接到图集内已有图，或新建一张子图。

### 3.4 画布（React Flow）

* 编辑模式：节点可拖动、可连线、可框选删除（Delete 键）；连线用默认贝塞尔。
* 浏览模式：`nodesDraggable/nodesConnectable/elementsSelectable` 关闭，仅平移缩放。
* 双击**图节点**：跳转进入引用的子图（两种模式均可）。
* 视野：`fitView` 初始适配；提供 Controls（缩放/适配）与 MiniMap，适配鼠标滚轮与触控板习惯。
* viewport 随图保存，回到某张图时恢复上次视野。

### 3.5 右侧详情面板（Drawer）

* 点击节点后从右侧滑出：
  * 浏览模式：只读展示标题、描述、（图节点）目标图入口按钮。
  * 编辑模式：表单编辑标题、描述；图节点可改指向的图；底部提供删除节点。
* 点击画布空白处或再次点击关闭。

## 4. 响应式与设备适配

* 桌面（≥1024px）：三栏布局常驻。
* 窄屏：左侧节点面板收起为顶栏按钮唤起的浮层；右侧详情 Drawer 全宽覆盖；画布手势平移缩放（React Flow 原生支持触控）。

## 5. 视觉基调：水边夜色 + 鹭羽青

深色工作台风格。深色让画布内容（节点、连线）成为视觉主角，长时间盯图不刺眼；分层底色靠明度差而非边框来营造空间感。色相上刻意与常见的靛蓝紫调深色区分：小鹭是水边的鸟，底色用**偏青的深蓝灰**（夜色水面），主色用**鹭羽青**（cyan），与项目图标身份一致。

### 5.1 设计原则

* **底色分层**：画布最深 → 顶栏/侧栏次之 → 卡片/弹窗最浅，三层明度递进；边框用低对比青灰，只在需要精确分界的地方出现。
* **克制用色**：不用渐变按钮；亮青只留给真正重要的交互态（激活、选中、focus），大面积保持安静。
* **签名元素**：等宽字体的路径面包屑，深色底 + 青色路径文字，形似终端里的文件路径，呼应"图有路径定位"的产品核心概念。
* **节点卡片走深色**：深色卡片 + 细描边，选中时青色描边 + 光晕；图节点用青色虚线双层框标识"层级/入口"。画布整体安静，高亮突出。

### 5.2 语义 token（Tailwind v4 `@theme` 定义，全局唯一取色来源）

| token | 值 | 用途 |
|-------|-----|------|
| `surface-0` | `#0b1014` | 画布、页面最底层 |
| `surface-1` | `#11181e` | 顶栏、侧栏、输入框底 |
| `surface-2` | `#182027` | 卡片、弹窗、节点 |
| `surface-3` | `#1f2a33` | hover 态、浮层菜单 |
| `line` | `#233039` | 常规边框、分割线 |
| `line-strong` | `#2f3f4a` | 卡片描边、输入框边框 |
| `fg` | `#e6edf3` | 主文字 |
| `fg-mute` | `#8b98a5` | 次级文字 |
| `fg-faint` | `#5c6873` | 占位符、弱信息 |
| `accent` | `#22d3ee` | 高亮青：选中、激活、路径 |
| `accent-deep` | `#0891b2` | 主按钮实底 |
| `accent-hover` | `#06b6d4` | 主按钮 hover |
| `danger` | `#f87171` | 危险操作 |

后续如需亮色主题，只需替换这组变量，组件类名不动。

### 5.3 画布适配

* React Flow 使用 `colorMode="dark"`（Controls / MiniMap / attribution 随主题）；点阵背景用 `line` 色，弱于节点。
* 连线默认青灰色，选中变亮青；节点选中态由全局 CSS 给 `.sm-node-card` 加青色描边 + 光晕。
